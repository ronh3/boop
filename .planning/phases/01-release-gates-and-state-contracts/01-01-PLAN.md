## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| committed source -> release checker | Package metadata, manifests, and Lua source are untrusted inputs to the gate. |
| release checker -> CI result | Non-zero checker exit blocks CI and protects artifact generation. |
| source manifests -> Muddler package | Manifest membership determines what Mudlet objects are packaged. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-manifest | Tampering | `check_manifests` | high | mitigate | Validate JSON and manifest/Lua parity recursively for scripts, aliases, and triggers. |
